# Benchmarking-Quantum-Classifiers-for-DNP3-Security-Scaling-Trade-offs
Reproducibility pipeline benchmarking quantum classifiers (VQC, QCNN, QSVM, QNN-DRU) on DNP3 network security. Evaluates angle/amplitude encodings, finite-shot reliability, mixed-state noise channels, FGSM adversarial robustness, and classical baseline trade-offs. Fully end-to-end with automated metrics, tables, and plots.
